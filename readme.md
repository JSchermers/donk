## General component for showing results from futball

It is a webcomponent for displaying the next and the previous match from the netherlands

`<sportlink-wedstrijd clientID=""></sprotlink-wedstrijd>`

### Properties

| Property    | Value |
| -------- | ------- |
| clientId  | [your_id] |
| pouleCode  | [your_id] |
